# NextVentures

A modern, scalable web application built with cutting-edge technologies to empower entrepreneurs and innovators in the venture ecosystem.

## 🚀 Features

- **Modern UI Framework** - Built with React 18 and TypeScript for type-safe development
- **Beautiful Components** - Leveraging shadcn-ui with Radix UI primitives
- **Responsive Design** - Tailwind CSS for elegant, mobile-first styling
- **Form Management** - React Hook Form with Zod validation for robust data handling
- **Data Fetching** - TanStack React Query for efficient server state management
- **Routing** - React Router v6 for seamless navigation
- **Data Visualization** - Recharts for interactive charts and graphs
- **Animations** - Framer Motion for smooth, delightful interactions
- **Theme Support** - Next-themes for light/dark mode switching
- **Developer Experience** - ESLint, TypeScript, and hot module reloading with Vite

## 📋 Prerequisites

- **Node.js** (v18 or higher) - [Install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)
- **npm** or **bun** package manager
